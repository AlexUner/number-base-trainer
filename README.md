# Системы счисления

Учебный тренажер для 8 класса. 24 пары и 48 направлений: 2 ↔ 8 и 2 ↔ 16.

- Знакомство с таблицей через карточки с открытием ответа.
- Активный ввод и возврат ошибок через 3-5 других карточек.
- Два правильных ответа подряд в каждом направлении для освоения пары.
- Последовательные блоки и смешанная практика.
- Полный итоговый тест из 48 вопросов и работа над ошибками.
- Сохранение прогресса в браузере и работа без сети после первого открытия.

Нет учетных записей, аналитики или серверной части. Двоичные ответы содержат все три или четыре цифры, включая ведущие нули.

Для локального просмотра запустите любой статический HTTP-сервер в этой папке. Для GitHub Pages укажите ветку main и корневую папку как источник публикации.
